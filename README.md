# Хидранти Варна

> Mobile-first PWA за бързо локализиране на най-близкия пожарен хидрант във Варненска област.
> *A mobile-first PWA for locating the nearest fire hydrant in the Varna oblast, Bulgaria.*

---

## За какво е

Леко уеб приложение, което показва на телефона позицията на потребителя и най-близките пожарни хидранти на картата. Работи в браузъра, без нужда от инсталация през app store.

**Целеви потребители:**
- **Пожарникари във Варна** — основни потребители, използване в реални ситуации
- **Доброволен отряд на гр. Варна** — за верификация на данните и обратна връзка

**Данни:** 3,934 хидранта в 5 общини — Варна (Изток и Запад), Девня, Долни чифлик, Провадия. Източник: ВиК Варна.

## Използване

### Достъп

Отвори линка в браузъра на телефона:

> 🔗 **[Live URL — попълни след deploy]**

Изисква се HTTPS — затова приложението е достъпно само през линка по-горе, не като свален файл.

### Добавяне на началния екран (препоръчително)

**Android (Chrome):**
1. Отвори линка
2. Меню (⋮) → **„Добавяне към началния екран"**
3. Появява се иконка като всяко приложение

**iOS (Safari):**
1. Отвори линка
2. Бутон „Сподели" (⬆️) → **„Добавяне към началния екран"**

### Първо стартиране

1. Дай разрешение за **достъп до локацията**, когато браузърът попита.
2. Картата центрира на твоята позиция и показва най-близките 5 хидранта.
3. Бутоните долу превключват между режимите:
   - **Близо <100м** — само хидрантите в радиус 100м
   - **Топ 5** — петте най-близки (по подразбиране)
   - **Всички** — всички 3,934 хидранта на картата
4. Tap на 🧭 — отваря Google Maps за навигация (ако разстоянието е >100м) или превключва компаса в самото приложение (ако е ≤100м).
5. Tap на 🚨 — отваря форма за сигнал за повреден/блокиран хидрант. Сигналът се изпраща по Viber / Telegram / SMS по избор.

### Внимание

⚠️ **Доброволните спасители не трябва да използват приложението за оперативна намеса.** То е инструмент за обхождане на терена и подаване на сигнали за състоянието на хидрантите, не заместител на координацията през 112.

⚠️ **GPS-ът зависи от сигнала.** В мазета, тунели и големи бетонни сгради може да не работи. В тези случаи използвай 📌 за ръчно поставяне на позицията си на картата.

## Стек

Един самостоятелен HTML файл (~672 KB), всичко вградено:

- [Leaflet 1.9.4](https://leafletjs.com/) — карта
- [MarkerCluster 1.5.3](https://github.com/Leaflet/Leaflet.markercluster) — клъстериране
- OpenStreetMap — картови плочки
- Vanilla JS / CSS — без build система, без npm dependencies в runtime

Хостинг: GitHub Pages (безплатен, статичен).

## За разработчици и AI агенти

Преди промяна по кода — прочети:

### Workflow

Проектът работи с три AI агента:
- **Claude (chat)** — архитектура, планиране, одит
- **Codex** — repo-aware планове и read-only анализи
- **Claude Code** — изпълнение на одобрени планове

Всички архитектурни решения и промени по dataset-а изискват потвърждение от собственика на проекта.

### Локално

Файлът `index.html` е self-contained — отваря се директно в браузъра. Geolocation API изисква HTTPS, затова в `file://` режим част от функционалността няма да работи. За локално тестване с GPS използвай GitHub Pages preview или локален HTTPS dev server.

## Данни

Хидрантите са парснати от 5 KMZ файла, предоставени от **ВиК Варна** (Водоснабдяване и Канализация — Варна ООД), оригиналният maintainer на инфраструктурата.

| Регион | Брой хидранти |
|---|---:|
| Варна Изток | 959 |
| Варна Запад | 1,014 |
| Девня | 100 |
| Долни чифлик | 541 |
| Провадия | 1,320 |
| **Общо** | **3,934** |

Координати: WGS84. Метаданни (адрес, тип, състояние): рядко попълнени в източника — около 16% от хидрантите имат адрес, останалите само координати.
