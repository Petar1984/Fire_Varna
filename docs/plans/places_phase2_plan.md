## 2 · Дизайнът

- **Д1 Износ (varna_3d, по неговия ред):** `src/export_fire_varna_places.py` (по образеца на `export_fire_varna_hotels.py`) → `data/fire_varna_places.json` = `{_meta:{generated, count, by_kind, licence_osm (дословно от poi `_meta.attribution` + „ODbL 1.0"), licence_registry (образецът на НТР: „отделни факти от регистъра …, източникът на всеки ред стои в src"), excluded:[{name, kind, src, why}]}, places:[{name, kind, lat, lon, zone, src, old_names, status}]}` — **8 ключа**, без `i`, без бележки, без кадастрални идентификатори. Подбор: (а) `places.json` venues със subtype ∈ {училище, детска градина, болница, ДКЦ, хоспис, университет}; (б) `poi_names` rows с chip ∈ {училище, университет, болница, детска градина}, БЕЗ `src ∈ {osm:building, правило У6}`, минус изключенията от атаката на Кими (таблица `EXCLUDED` в скрипта, поименно, с довод); дедупликация: регистровото място води; OSM ред, чиято сграда (`i`/`yards`) е на място от (а) или чието име (skel) съвпада на ≤ 60 m — отпада поименно в `excluded` („дублет на …"); `old_names` = OSM-псевдонимите (`alias`) + старото OSM име при регистров override; `status` = „бивш" при „бивше …" в името; `zone` = `place_zones.zone_of(lat, lon)`; `src` ∈ {„OSM", „Регистър на училищата (МОН/НЕИСПУО), одобрено 21.08", „Регистър на лечебните заведения (ИАМН)", „Регистър на училищата и детските заведения (Община Варна)"}; `kind` ∈ {училище, университет, болница, ДКЦ, хоспис, детска градина}. Гейт `src/qa_fire_varna_places_export.py`: count == `_meta.count`; 8 ключа точно; enum-и; кутията; 0 кадастрални; **PII**: телефон/имейл/ЕГН = 0; „д-р/доктор + фамилия" без институционална дума (ОУ/СУ/ПГ/ДГ/МГ/МУ/МБАЛ/СБАЛ/СБАГАЛ/УМБАЛ/гимназия/училище/университет/болница) = 0; уникалност (skel(name), zone) = 0 дублети; всяко изключване поименно; UTF-8 LF; лицензните редове дословно; тича и пада (нарочна повреда).
- **Д2 Fire_Varna данни:** `data/places.json` = проследеният LF-blob на varna_3d (`git show HEAD:data/fire_varna_places.json`, §14-поуката); sha/байтове се мерят при копирането и се заковават (тест + константа `PLACES2_SHA256`).
- **Д3 Клиентът (`initPlacesSearch`, само добавки):** втори товар през същия `fetchValidatedJson` (валидатор за 8-те ключа/enum-и/кутия/`_meta.count`); записите влизат в същия индекс с `kind`; **класът на записа** = `kind` (K2 важи: формите на речника „училище/училища/училището…", „университет…", „болница…", „детска градина/градина", „дкц", „хоспис"); **групи в рендера**: редовете се групират по клас в реда на най-добрия резултат във всяка група; хедър по клас: Хотели · Училища · Университети · Болници · ДКЦ · Хосписи · Детски градини (думите за подпис на Петър при Gate 2); чип по клас: хотел · училище · университет · болница · ДКЦ · хоспис · детска градина; попъп: заглавие = име (+ „(бивш)"), ред 2 = вид · зона (за хотел: вид · ★ · легла · зона), „старо име: …", **ред-източник** по `src`: OSM → `име: © OpenStreetMap contributors (ODbL) · координати: КАИС Отворени данни (АГКК)`; регистрите → `име: <регистърът дословно от src> · координати: КАИС Отворени данни (АГКК)`; nav-линковете; оранжев пин за всички класове (цветът по клас — не тази нощ).
- **Д4 Подредбата при ключ (Петър):** ако заявката носи КЛЮЧ и имаме ≥1 ред → нашият контейнер стои на мястото на адресния (top: calc(100% − 2px)), а `#addrSearchResults` се измества под нас с inline `style.top = (ours.offsetTop + ours.offsetHeight) + 'px'`; при скриване на нашия списък / без ключ → `removeAttribute('style')` на техния (никакъв остатък `style=""` — G3-байт-равенството за корпуса без ключ остава); преизчислява се при всяка мутация (наблюдателят от Д5/В6). Без ключ — както днес (адресите първи). Enter при ключ: ако нашият списък е видим за текущия текст с ≥1 ред, Enter избира нашия първи ред (ключът е изричното намерение) — освен ако адресният списък съдържа ред с ТОЧНО съвпадение на всички токени (тяхната `allTokens`-логика не е достъпна; приближение: техният първи ред без размити маркери — Сол да каже дали е измеримо отвън; иначе Enter при ключ = наш).
- **Д5 Попъпът (бъгът на Петър):** самовъзстановяване само ако ДРУГ попъп (елемент ≠ нашия) е заел слота; × затваря (C10, вече поправено отделно).
