## Какво прави Петър (една вечер)
Рисува или одобрява ~35 полигона на жилищните квартали/местности върху НАШАТА карта (никога върху Esri сателит — лицензът), с подложка OSM/КАИС-отворена; всеки полигон: регистров код, име, `signed_by`, дата, `basemap`, `method`, `precision_m`, `version`, `license`. Нови имена (Цветен квартал) — само с втори свидетел (OSM възел / КАИС адресен текст). Едно „не съм сигурен“ = полигон без подпис = мястото остава район.

## Какво прави темата (ред)
ADR 010 „Граници, подписани от човек“ (Кими + Astra оборват, Петър приема) → инструмент „режим граница“ на локалната карта (GeoJSON с provenance) → подписът на полигоните → P8 (varna_3d: канал `SIGNED_POLYGON` в стълбата, ръб = `SIGNED_POLYGON_BORDER`, гейтове: валидност, припокриване ≤ precision_m машинно, всяко място в ≤ 1 полигон, 1:1 с регистъра, диф по версия с праг) → F13 (Fire_Varna: данните; търсенето — нормализация на съюзи/точки, „фраза = точно един квартал“ бие ветото, уточнител при неуникалност, родител ⊃ дете; манифест; замразяване по правилата на A) → пуш → „училище цветен квартал“ дава 3 ОУ „Ангел Кънчев“.

## Какво НЕ е
Не е връщане към машинните обвивки (IoU 0,13). Не е OSM като съдия (няма полигони). Не е поправка на едно училище.
