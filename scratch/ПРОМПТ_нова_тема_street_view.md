## Проучването-основа (свършено 31.08 — НЕ го повтаряй, ползвай го)

- **Еталонът във varna_3d** (`web/index.html`): бутонът „снимки наоколо" (~5144),
  metadata потокът (~5375, ~5689: `maps.googleapis.com/maps/api/streetview/metadata`),
  прозорчето (~5414: `www.google.com/maps/embed/v1/streetview`), ключът — ръчно
  въвеждане „въведи ключ" (~569), пази се локално. **Гейтът `src/qa_google_endpoints.py`
  забранява платения static-image ендпойнт структурно** — пренася се и тук.
- **Икономиката (потвърдена с първоизточници, 31.08)**: Maps **Embed** API — безплатен,
  без лимит (и в 2026); **metadata** — „no charge, no quota is consumed"
  (developers.google.com/maps/documentation/streetview/metadata). Единственият платен
  path е static image — забраненият.
- **Кими (условно GO, каналът Project_wiki.kimi.log, 31.08)**: петте условия —
  (1) НОВ отделен ключ (никога този от 3D-то), API restriction + квота; (2) нула
  кеширане на Google съдържание (офлайн копието деградира до линк); (3) fallback към
  сегашния безключов линк при всичко (без покритие/изчерпана квота/офлайн); (4) bottom
  sheet + lazy mount чак при докосване (iframe-ът гълта жестовете); (5) **писмен
  лицензен отговор с цитати от ToS преди билд** (Правилото 4, Phase-0 стил) — ToS
  твърденията от проучването са по памет и искат първоизточник.
- **Квотната конфигурация**: Street View Static API → дневна квота **0** (metadata по
  документация не консумира квота → трябва да оцелее; **smoke-тест в първия ден**:
  ако 0 блокира и metadata → символичните ~50/ден при 10 000 безплатни месечно).
  Embed — няма какво да се капва. Всички други API-та — изключени от ключа.
- **Сол (кодовата карта, 31.08 — пълният текст в `C:/Projects/.agents/channels/C--git.gpt.log`, последният запис). Главното:**
  - **sw.js ВЕЧЕ е чист**: прескача всичко извън собствения origin (sw.js:164–203) —
    Google никога не се кешира; изискването е изпълнено по рождение. Но офлайн shell-ът
    ЩЕ покаже UI-а → SV бутонът да се крие/деградира до линк при липса на мрежа.
  - **CSP няма** (и не трябва да се добавя сега — това е отделна голяма задача);
    нищо не блокира metadata/iframe.
  - **СЕДЕМ споделени nav call-site-а** ползват общия helper — SV бутонът се закача
    на КОНКРЕТНИТЕ места (входовия панел ~5532 първо), НЕ в helper-а (същият урок
    като Waze договора).
  - **iframe-ът със `referrerpolicy="strict-origin-when-cross-origin"`** — иначе
    пълният URL с ?lat/?lon deep-link-овете изтича към Google; + `allowfullscreen`,
    минимум 200×200 px (при header + 45vh sheet мястото е тясно — мери).
  - **Referrer рестрикцията**: `petar1984.github.io` е ОБЩ origin за всичките Pages
    проекти; при strict policy пътят не се праща → рестрикцията е `https://petar1984.github.io/*`
    (по-широка — приета сделка) + отделен dev ключ за `http://localhost:*`.
  - **Ключовият validator на 3D-то** проверява ключа през metadata → Embed-only ключ
    би паднал на validator-а; реши: един ключ с двете API-та (+квота 0 на Static)
    или два ключа с преработен validator. API restriction сам НЕ различава безплатния
    metadata от платения image path в едно API — затова гейт-тестът + квотата са
    отделният пласт.
  - **Еталонният поток прави ~9 metadata заявки на отваряне, без timeout** — за
    мобилна мрежа: timeout + дедуп + отличаване „няма покритие" / „изчерпана квота" /
