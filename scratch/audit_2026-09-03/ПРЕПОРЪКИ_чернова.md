## В · Лотът „места по функция" (ПМФ) — чернова на плана (числата идват от мярката `kais_func_2026-09-03`)

**Целта (думите на Петър):** „като напиша квартала и детските градини — да излизат точно колкото са; идентифицирани по име, ако няма — адреса".

**Изворът на пълнотата:** КАИС функцията на сградата — „Сграда за детско заведение" (214 тела в града), „Сграда за образование", „Здравно заведение" (и настаняване, ако има) — групирана в парцели. Парцелът е единицата „заведение": едно място на парцел (или N, ако регистърът дава N институции на адреса).

**Стъпки:**
1. **Мярка (тича):** парцели по функция × район; доставени / кандидати; името на кандидата по три извора в ред: регистър по адрес → КАИС addr низ (носи имена като „ЦДГ 10 - ПРИКАЗКА") → OSM ≤40 m; иначе „без име"; обратно: доставени места на чуждо тяло / >60 m.
2. **Правилото за реда (без измисляне):** име = регистровото (главно) / КАИС-носеното / OSM; без име → „Детско заведение — ул. Ниш 29" (функция + КАИС адрес; `src` = „КАИС функция + адрес"; `status` = ''); kind по функцията (детска градина / детска ясла / училище / университет / болница…, при спор — регистърът); zone по стълбата (както всички); пин = центроид на най-голямото тяло на парцела.
3. **Конвейерът (varna_3d):** нов вход `src/places_by_function.py` (КАИС функция → парцели → съединение с регистрите и OSM) → влиза в `export_fire_varna_places.py` като трети извор (след регистъра и OSM), с дедупликация по парцел (регистърът води); QA: всяко ново място лежи ВЪТРЕ в тяло с вярна функция; две места на <5 m = червено (решение 4); бройката по квартал = броят парцели с функцията (гейт).
4. **Клиентът (Fire_Varna):** нов kind „детска ясла" → речникът (форми) + KIND_GROUP („Детски заведения" — UI дума за подпис); нищо друго — А3′ (решение 1) прави „детска градина владиславово" пълен списък.
5. **Гейтове:** (а) по квартал: „детска градина <квартал>" връща ТОЧНО броя парцели с функцията в семейството на квартала (за всички квартали с ≥1); (б) всеки нов запис: име с извор или адресна форма; (в) фикс-извадка за окото на Петър — Владиславово (4-те контролни точки + Маргаритка + Приказка), после 5 от другите класове; (г) старите 103 + новите заявки; G3 байт-равен; тестовете.
6. **Комити:** P2 (varna_3d: скриптът + QA + `fire_varna_places.json`), C22 (Fire_Varna: данните + речникът + KIND_GROUP + гейтът), C23 (docs), одит.

**Известни рискове (за атака):** функцията в КАИС е „по предназначение", не „по ползване" — сграда за детско заведение може да е затворена градина/сменена функция (→ status?); парцелът може да слепи две институции; регистровият адрес „до бл. N" е на квартала, не на блока (Владиславово); OSM-имената в изключените (частни без номер) могат да се върнат през парцела.
